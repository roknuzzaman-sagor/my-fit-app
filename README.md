# my-fit-app

FitLog is a modern workout tracking and fitness planning web application built with Next.js and TypeScript. It allows users to explore different workouts, view detailed exercise information, create a personal workout plan, and save workouts for later.

##  Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- Next/Image
- REST API
- LocalStorage
- Git & GitHub

##  Key Features

### 1. Workout Library
Browse a collection of workouts with information such as difficulty, muscle groups, duration, rating, and description.

### 2. Workout Details
View complete information about a workout, including equipment, sets, reps, calories burned, rating, and step-by-step instructions.

### 3. Personal Workout Plan
Add unlimited workouts to your personal plan and easily remove or mark workouts as completed.

### 4. Save Workouts
Save your favorite workouts for later and access them from the **My Plan** section.

### 5. Sorting & Progress Tracking
Sort workouts in your plan by duration, calories, or rating and track total exercises, workout time, and estimated calories burned.
